# 发育式 SNN 结构形成 — 设计文档

> 2026-11-27 修订 v2：修复"探索空转/骨架未形成"问题
> 2026-11-26 初版 v1：四阶段发育框架

## 背景

生产 SNN 网络 222 神经元/222 边，但发育骨架未形成有效功能结构（2026-11-27 实测诊断）：

| 分区 | 神经元 | 边 | 状态 |
|---|---|---|---|
| 核心(0-39) | 40 | 63 内部 + 66 固定中继 | ✅ 干净 |
| 动态输入(40-99) | 60 | 50 内 + 28→输出 | ⚠️ 探索边弱 |
| 动态输出(100-199) | 100 | **0 出边** | ❌ 死端 |
| 连续调制(200-209) | 10 | 12 | 固定 |
| 连续中继(210-219) | 10 | 0 内 | 固定 |
| 概念(220+) | **2** | 15 | ❌ 仅 220/221 |

## v1 问题根因（代码证实）

1. **探索覆盖缺陷**：`explore_synapses` 全对遍历 40-199，`attempts` 上限 `max_new*20=1000` 从 src=40 耗尽 → 连接集中在低 ID，输出区(100-199)轮不到。实测 dyn_out **0 出边**（死端）。
2. **步长演化未接入发育**：`explore_synapses` 固定 `step=1`，从不调 step_evolve。步长演化只在 `train_from_feedback`（学习路径）→ 发育边步长全 1。
3. **探索-修剪死循环**：探索边权重 `0.15-0.40`，`keep_weight=0.20`——大量边 <0.20 被剪。`explored=1274/pruned=1196` 空转证据。
4. **概念区缺失**：生产网络文件本身只有 220/221（恢复基线缺 222-232）。

## v2 修复设计

### 1. 探索算法：分功能区配额（非全对遍历）

探索不再"从低 ID 全对遍历 + attempts 上限"，改为**分功能区配额**：

- **输入区(40-99)**：探索连到语义区/中继/隐藏层
- **输出区(100-199)**：探索连到概念区(220+)/核心输出(32-37)——**打通决策链**
- **语义区(220+)**：参与探索，建立概念→输出映射

每个功能区有独立探索预算，保证覆盖均匀，不再低 ID 集中。

### 2. 功能链保证（感知→语义→决策）

探索时显式建立三环链路：
```
感知(40-99 输入槽) → 语义(220+ 概念) → 决策(32-37 核心输出)
                ↘ 中继(230+) → 隐藏层(17-26) → 输出
```
输出区(100-199)必须连到核心输出/概念区，消除死端。

### 3. 探索边权重重设

`explore_weight_min=0.35, max=0.55`（> keep_weight=0.20），骨架能稳固，停止空转。

### 4. 步长演化接入发育

探索后用 SNN 的 `_apply_structural_plasticity`（或独立演化函数），让发育边按协同放电演化步长（多尺度，不再是全 1）。

### 5. 概念区恢复

基线网络缺概念神经元。发育时若概念区神经元不足，补建概念输入 + 中继，参与探索。

## 安全约束

- **核心区(0-39)完全不动**：`plasticity_core_freeze` 保护，探索/修剪/步长演化均跳过 <40
- **eval 12/12 回归门**：任何改动后必须验证
- **收敛机制保留**：`max_dev_edges=120 + prune_ratio=0.35` 防过度生长

## 验证计划

1. 单元测试：分区域探索覆盖、输出链打通、步长演化、权重稳固
2. 集成测试：development_tick 后功能区都有边、eval 12/12
3. 生产部署：干净基线重新发育，验证功能链 + eval 12/12

# SNN 发育架构（Development Architecture）

> 设计文档：把现有硬编码 SNN 升级为"增殖→分化→突触探索"的发育式网络。
> 依据用户 2026-11-26 洞察：人脑神经元先增殖再分化，突触从无到有探索；
> 当前 SNN 增殖分化的网络骨架未形成，更谈不上认知。

## 现状诊断（2026-11-26 实测）

生产网络 233 神经元 / 170 边：
- **固定核心 0-39**：40 神经元 / 69 内部边 —— 唯一真正工作的（手工硬编码）
- **动态输入槽 40-99**：60 神经元 / **0 内部边**（仅 1 个神经元 40 接入固定隐藏层 16-27）
- **动态输出槽 100-199**：100 神经元 / **0 边**（完全孤悬）
- **连续调制 200-219**：固定功能中继
- **概念区 220+**：13 神经元 / 3 内部边（概念注册）

**结论**：增殖了 160 个动态神经元，但 0 条动态内部边——骨架未形成。
`_connect_dynamic_exploration` 只把新输入连到固定隐藏层 16-27，动态区之间无互连。

## 目标：四阶段发育

```
Stage 0  胚胎     : create_default 硬编码骨架（40 神经元，含先验知识）
  ↓
Stage 1  增殖期   : 大量生成未分化神经元（动态区扩容），不接线
  ↓
Stage 2  突触探索 : 突触从无到有，弱随机连接互相试探，STDP/强化收敛
  ↓
Stage 3  分化期   : 自发分簇成功能脑区（感知/语义/决策）+ 弱引导
```

## 多模态无感映射

`CognitiveCoder.encode()` 已支持 text/visual/audio/structured → 统一概念向量
（`ConceptVector`），多模态共识提升置信。**缺口是数据集**——没有跨模态
训练样本让对齐层学习"同事物不同模态 → 同一概念"。

需要：
1. 构造/收集多模态数据集（同一概念的多模态表示）
2. 训练对齐（对比学习：正样本=同概念跨模态，负样本=异概念）
3. 无感映射验证（不同模态输入 → 同一概念神经元簇）

## 弱引导信号（避免完全乱分化）

自发分簇需弱引导，防随机分化成无意义结构：
- **标签/概念先验（弱监督）**：已知概念（apple/danger/urgency）给出先验特征
- **共同激活频率**：常共同激活的神经元倾向同簇（统计引导）
- **化学亲和梯度**：弱空间梯度，近邻倾向相连（拓扑引导）
- **侧向抑制**：同簇内竞争，防过度收敛（局部抑制）

## 验收标准

1. 动态区（40-199）内部边 > 0（骨架形成）
2. 自发分簇产生 ≥3 个功能簇（感知/语义/决策），非随机
3. 无感映射：同一概念不同模态 → 同一概念神经元激活
4. 生产 eval 保持 12/12（不破坏现有决策）
5. 发育过程可观测（阶段/分簇/边数统计可查）
